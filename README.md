# TLB Performance Analysis and Address Translation Simulator

** Computer Organization and Architecture**

## Project Description
This project simulates Translation Lookaside Buffer (TLB) performance and virtual-to-physical address translation using a page table.

## Features
- Virtual address translation
- TLB hit and miss tracking
- FIFO and LRU replacement policies
- Configurable TLB capacity
- Performance visualization dashboard

## Technologies Used
- Python
- Streamlit
- Matplotlib
